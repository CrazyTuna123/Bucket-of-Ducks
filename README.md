# Bucket of Ducks
This is my submission for the GMTK Game Jam 2026. This is also the first game I've ever made that wasn't on Scratch.

Move your mouse around to control your bucket and catch as many rubber ducks as you can within 60 seconds. Every duck you catch adds 2 seconds to the countdown, but every one you miss takes away 10 seconds. The ducks start falling more frequently and faster as the game progresses.
